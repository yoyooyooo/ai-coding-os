# Goal Proof Sources

本目录保留已被消费但仍有追溯价值的 Goal Proof source material。

## Owns

- 已转成 Goal Pack、docs authority、review ledger 或 implementation artifact 的历史 proposal / handoff / source note。
- 追溯链接：source 是后续 artifact 的输入，不是当前执行状态。

## Must Not Own

- 当前 Goal Pack 运行状态、active work item、completion review 或 evidence chain。
- 当前 SSoT、standard、ADR、roadmap gate 或产品事实。
- 开放候选；开放候选留在 `../inbox/`。

## Boundary

Sources 不是 backlog。若 source 已被转成 Goal Pack，以 `../goals/<goal-id>/` 为当前状态权威。
若 source 已被 promote 到 SSoT / standards / ADR，以对应长期层为权威。
