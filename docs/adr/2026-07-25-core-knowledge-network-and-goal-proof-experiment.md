# ADR: Core Knowledge Network And Goal Proof Experiment Boundary

- Status: superseded-in-part
- Date: 2026-07-25

## Context

早期 Core 仍混合知识 Owner、线性 `Read First`、执行方法与 Goal Proof 实验，容易把 Route 误解成固定 Workflow。

## Decision

- Route 是可发现边，不是强制顺序。
- Core 只拥有知识、治理、产品、架构、Proof、Preset 和确定性 Tool；外部 execution method 独立拥有任务分解、依赖、状态和完成。
- Preset 只输出 candidate，Evidence 只支持有界 Claim。
- 文档层、Registry、Artifact Graph 和固定 Handoff 只有在真实压力下 Earn。

## Current Disposition

上述 Route、Authority、Evidence 与 Earned Shape 原则继续有效。Goal Proof 已不在当前交付快照中；当前 Core 进一步加入跨语言 EAA、局部 ADIR、Skill evaluation 和 Capability-responsive Suite evolution，见 2026-07-26 ADR。
