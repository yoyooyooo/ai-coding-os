# Suite Evolution Standard

> **Preserve Semantics; Re-earn Scaffolding and Conventions.** 体系演进不是持续增加规则，而是让稳定语义长期存在，让承载它们的形式持续证明价值。

## Diagnose before adding guidance

Agent 表现不佳时先区分：

```text
Accepted Meaning or Authority missing
source hides capability, writer, or lifetime
run / reproduction command missing
First Wrong State not observable
type, contract, test, monitor, or tool could prevent the failure
route loads wrong or excessive knowledge
Portable Default missing, causing repeated dialect invention
instruction is ambiguous or wrong
one-off execution mistake or evaluator error
```

优先改善项目知识、源码边界、类型、命令、测试、日志和工具。新的 Prompt rule 是最后的长期 Owner。

## Mechanisms must earn their keep

新的强指令、Reference、Template、Schema、Registry、Role、Framework 或 Skill 应说明：

```text
protected meaning or recurring material failure
why a lower and more reliable owner cannot carry it
independent semantic problem and change axis
smallest falsifiable behavioral difference
context and maintenance cost
override, merge, or retirement condition
```

行业流行、结构完整、旧模型局限和一次失败不构成准入证据。

## One failure, one lowest reliable owner

学习应落到最低可靠防线，不在多个 Skill 重复提醒：

```text
product term / Accepted Meaning
source boundary / type / contract
use case / Port / state owner
test / monitor / command guard
tool or project knowledge
Skill instruction only when the failure truly remains semantic and cross-project
```

## Skill independence

独立 Skill 至少需要：独立语义 Authority、独立变化原因、可独立触发和失败，以及合并后会真正混淆 Owner。总与另一节点共同触发、同步变化或只拥有输出格式的节点应合并、降为 Reference 或退出。

## Strong-Agent correction

**A Strong Agent Does Not Make Defaults Obsolete.** 如果一个短 Default 反复降低跨项目重复发明、搜索、Review 和 Tooling ambiguity，它仍然有价值。反过来，熟悉也不是保留理由；Convention 必须保护真实 invariant、低成本且可安全覆盖。

## Anti-Cargo-Cult

**Do Not Build Coconut Airports.** 新模型、框架、Agent role 或方法论只能触发调查，不能自动授权复制外形。理解本地瓶颈、机制、权力、反馈和代价后，再决定是否采用。
