# Progressive Disclosure

## Knowledge node shape

主 `SKILL.md` 只保留：

```text
owned semantic question
few high-entropy anchors
minimal causal model
recognizable pressures
critical boundaries and local agency
owner-local portable defaults
routes to conditional depth
adjacent owners only where the relation changes the judgment
```

Reference 围绕一个稳定问题或因果关系，而不是某一流程阶段。Template 和 Example 提供可复用形状，但不自动成为项目必须产出的 Artifact。

## Contextual edges

一条边只有在相邻知识可能改变当前判断时才出现。常见语义包括：

```text
continue into   当前问题需要更深的机制或边界
contrast with   两个概念容易被混淆，需要保持区别
related when    某种额外压力出现时才相关
return to       回到当前 Owner 的局部地图
```

不要为“网络看起来完整”机械生成全互链，也不要把链接顺序解释成执行顺序。

## Compressed and decompressed layers

高熵短句负责现场唤醒：

```text
One Fact, One Final Writer.
Intent Is Not Fact.
Scope Owns Lifetime.
Find the First Wrong State.
```

同一节点随后必须给出正式含义、反例、适用边界和具体路由。只有口号没有解压会形成私有方言；只有长解释没有压缩会增加恢复成本。

## Context budget

Agent 只加载能够改变当前判断的最小充分上下文。主 Skill 不重复 Reference，项目 Docs 不复制 Skill 全文，Router 不复制 Current Truth。高频关键原则可以在正确入口局部重述，因为 DRY 管的是语义 Authority，不是禁止必要上下文。

## Writing consistency

全套 Skill 使用同一叙事习惯：

- 先说明拥有的问题和不拥有的问题。
- 使用因果与对照，不使用固定阶段完整性。
- `must / never / always` 只保护稳定语义、安全边界或受保护失败。
- 默认值明确标为 Default，并说明 Project Override。
- 技术知识保持具体，删除其不必要的 Ladder、Gate 和统一成熟度包装。
