# 2026-07-26 Snapshot Convergence Report

- AI Coding OS 作为 Agent-legible 项目认知、决策与验证基础设施的定位。

- 独立 `$architecture-decision-system`、`$skill-evaluation-system` 和 `$ai-coding-os-evolution`。
- `application-core` / Monorepo / TypeScript / Rust Preset Profile 解耦。

- `docs/review-plan`、空的 `docs/interface-capabilities` 与空的 `docs/product-harness` 分类外壳因缺少 Earned Current Home 被移除；相关长期语义继续由对应 Skills、当前 ADR、Standards 和 Evals 拥有。
