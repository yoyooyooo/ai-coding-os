# Project Materialization

ADIR is an interpretation protocol, not a mandatory `docs/architecture-ir/`
layer. `$docs-governance` decides Current Home and shape.

## Earned Persistence

```text
L0 Implicit Slice IR
  temporary working model; no artifact

L1 Decision Trace
  durable rationale or handoff value

L2 Durable Architecture Slice
  cross-Agent, cross-language, or migration sharing

L3 Project Architecture Model
  multiple slices require diff, health, or common projection

L4 Machine-Validated IR
  CI, generator, visualization, or other real consumer exists
```

## Natural Homes

```text
current topology / writer / boundary -> docs/architecture/**
accepted technical tradeoff          -> docs/adr/**
binding project rule                  -> docs/standards/**
point-in-time health or audit         -> docs/reports/**
future sequence and deletion gate     -> docs/roadmap/**
unaccepted target                     -> docs/proposals/** when earned
```

Architecture profiles and Preset overlays may seed candidates. They do not
become current architecture merely because they are structured.
