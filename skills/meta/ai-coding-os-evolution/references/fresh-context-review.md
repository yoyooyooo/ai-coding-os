# Fresh-context Review

Separate author, critic, and release evidence where consequence justifies it.

Use lanes with different information:

- clean-room review detects current friction without historical anchoring;
- failure archaeology prevents deletion of rules that protect real regressions;
- first-principles rebuild reveals path dependency;
- capability maximization searches for interfaces, Tools, rubrics, and dynamic Harnesses;
- adversarial review challenges candidate assumptions and transfer;
- project simulation checks real repository work.

Synthesis should receive traceable findings, not private reasoning transcripts.
