# Compatibility and Support Envelope

Declare one primary Agent Capability Baseline for canonical Skills.

A compatibility overlay is earned when:

```text
a real secondary profile is supported
protected tasks fail without additional scaffolding
additional guidance is bounded and does not alter semantic ownership
its context cost is not imposed on the primary profile
```

Report `not_evaluated` profiles honestly. Cross-model transfer from one held-out
corpus is evidence, not a permanent universal guarantee.
