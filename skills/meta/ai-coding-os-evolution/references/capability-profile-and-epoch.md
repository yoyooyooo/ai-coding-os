# Capability Profile and Epoch

```text
Agent Capability
  = model
  × reasoning mode
  × context loading
  × Skills and tools
  × Harness and memory
  × subagents / dynamic workflows
  × permissions
  × cost and latency budget
```

A new model, tool, context loader, or Harness triggers a Capability Probe. Start
a full evolution epoch only when measured differences can change Suite utility,
context cost, autonomy, or protected failures.

Record current and previous profiles, task classes, support status, and the
unknowns not evaluated.
