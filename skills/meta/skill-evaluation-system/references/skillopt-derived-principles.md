# SkillOpt-derived Principles

This system adopts the following mechanisms from Microsoft SkillOpt as bounded
ideas, not as a requirement to vendor its implementation:

```text
rollout -> reflect -> aggregate -> select -> update -> gate
bounded textual change budget
validation-selected checkpoints
rejected-edit memory
longitudinal improved/regressed/persistent-fail/stable-success comparison
compact cross-epoch optimizer memory
experience replay and staged adoption
```

Adaptations for AI Coding OS:

```text
one Skill document -> multi-owner Suite and project knowledge network
single task score   -> hierarchical semantic, behavioral, and efficiency gates
edit count          -> risk-weighted semantic change radius
trainable prompt    -> executive strategy and retrieval surface only
held-out score      -> evidence for behavior, never semantic Authority
```

Use SkillOpt as an optional execution backend only after the Evaluation Slice,
corpus, Oracle, and ownership boundaries are already defined.
