# Experience Intake

Real sessions can provide Discovery/Train evidence when recurrence and a
checkable signal exist.

```text
harvest locally and read-only
redact secrets and sensitive business data
mine recurring tasks and human corrections
review task files before external provider calls
replay in isolated contexts
attribute failures
stage candidates behind held-out gates
adopt explicitly with checkpoint and rollback
```

One human correction is not automatically a Suite rule. A project-specific fact
is not automatically a reusable Skill instruction. Exposed Test cases should be
rotated or retired from sealed use.
