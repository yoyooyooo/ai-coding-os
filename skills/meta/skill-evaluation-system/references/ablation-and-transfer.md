# Ablation and Transfer

Each strong instruction is a hypothesis that its absence causes a material
failure. Compare:

```text
Current Suite
Candidate Suite
Minimal Kernel
No Skill / No Suite when meaningful
Previous Agent Capability Profile or compatibility overlay when needed
```

Possible dispositions:

```text
retain      protected invariant or measured failure prevention
narrow      useful only under explicit pressure
move        place in an on-demand Reference
interface   replace prose with a stronger Tool/Schema/type boundary
tool        replace repeated judgment with audit/lint/test
rubric      let the Agent act, then evaluate quality
overlay     keep only for a specific support profile
delete      no measured utility or net harmful context cost
```

Repeat stochastic runs and compare matched seeds where possible. Transfer tests
should reveal whether the candidate overfit wording, one evaluator, one Harness,
or one model capacity.
