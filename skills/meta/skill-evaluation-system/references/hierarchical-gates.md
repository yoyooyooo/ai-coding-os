# Hierarchical Gates

```text
Gate 0 Evaluation Integrity
  clean splits, valid Oracle, source/corpus hashes

Gate 1 Mechanical Integrity
  links, schema, tooling, packaging, source hygiene

Gate 2 Constitutional Invariants
  Authority, ownership, no silent material assumption, claim boundaries

Gate 3 Protected Regression
  high-risk cases and historical human corrections do not recur

Gate 4 Behavioral Utility
  task success, unknown discovery, autonomous judgment, recovery

Gate 5 Efficiency
  context, tokens, latency, tool calls, output bloat, unnecessary escalation

Gate 6 Transfer
  other Agent profiles, Harnesses, and unseen repositories
```

A candidate may pass by materially improving behavior, or by preserving behavior
while materially reducing context and coordination cost. Hard semantic failures
cannot be averaged away.
