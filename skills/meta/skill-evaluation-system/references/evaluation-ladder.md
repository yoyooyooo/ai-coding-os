# Evaluation Ladder

```text
L0 Static Contract
  frontmatter, links, schema, eval declarations, ownership, portability

L1 Direct Skill Eval
  target Skill is explicitly loaded; isolates its behavioral contribution

L2 Routed Composition Eval
  starts from a user request; tests routing and multi-Skill ownership

L3 Repository Task Eval
  real files, tools, commands, tests, and bounded artifacts

L4 Long-horizon Eval
  implementation-time discoveries, recovery, handoff, and claim closure

L5 Field / Canary Evidence
  real use, human corrections, recurrence, cost, and post-release drift
```

A higher level does not erase lower-level contracts. State the highest verified
level and the unverified adjacent behavior.
