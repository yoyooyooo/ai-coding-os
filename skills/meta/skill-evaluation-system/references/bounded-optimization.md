# Bounded Optimization

A textual edit count is not a sufficient change budget. Classify semantic radius:

| Level | Change | Default control |
| --- | --- | --- |
| E0 | wording, duplicate removal, Reference route | automatic candidate and gate |
| E1 | one Skill's local executive strategy | behavioral gate |
| E2 | trigger description, Router, cross-Skill handoff | composition eval |
| E3 | shared contract, owner map, architecture doctrine | semantic owner review |
| E4 | Suite constitution, compatibility, release contract | explicit Suite release decision |

Candidate operations:

```text
keep
narrow
move to Reference
replace with interface/tool/test
convert to rubric/eval
move to compatibility overlay
delete
```

Every hard instruction should protect a stable invariant or an observed,
protected failure. Otherwise it is an ablation candidate.
