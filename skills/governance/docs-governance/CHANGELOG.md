# Changelog

## Local-blocker and implementation/observation closure

- Scoped unresolved Authority, cleanup, and external-decision blockers to the affected convergence or mutation while continuing unrelated governance work.
- Split implementation existence from observed behavior and removed the duplicated full Authority table from the Skill entry.
- Accepted explicit Preset `candidate-snapshot` mode without treating generated proposals as project Authority.
- Made the direction-neutral Evidence Envelope optional under real machine-consumer or durable handoff pressure.

## Minimal knowledge-kernel convergence

- Defined SSoT as the canonical Current Home for shared semantics within scope rather than a globally highest Authority.
- Replaced residual per-question arrow rankings with semantic-owner, binding-constraint, implementation-evidence, and observed-evidence relations.
- Added bounded change-impact obligations without defining propagation order or a new state machine.
- Removed the redundant Human-Agent Documentation SOP and default Decision Queue shape; durable unresolved decisions now use an established project decision Home only when earned.
- Corrected source alignment so source proves implementation structure/static properties while runtime and reachability require executed or observed Evidence.

## Suite protocol integration

- Added claim-bounded Product, Harness, and selected-execution-method evidence handoff through the optional Suite Evidence Envelope.
- Kept documentation claim class, lifecycle, evidence level, placement, and acceptance decisions owner-local.
- Added adjacent owner discovery without turning Docs Governance into product or execution authority.

## v2.0.0-rc.1 — Evidence-aware earned-shape audit

- Converged the public model on `Authority`, `Earned Shape`, and `Evidence`.
- Reduced the default Skill path to Locate, Classify, Route, Converge, and Verify, with task-scoped reference pointers.
- Added independent Claim Class, Document Lifecycle, and Delivery/Evidence axes.
- Made flat Roadmap routes and earned capability capsules equivalent future-route forms; removed fixed capsule chapter/frontmatter assumptions.
- Made Artifact Graph and readability checks explicit extensions; graph metadata is opt-in and absent graph metadata produces no graph audit findings.
- Made docs baseline and repository entry checks conditional on observed project structure rather than a fixed layer tree.
- Added evidence-driven repository topology reporting and managed AGENTS.md marker validation.
- Centralized scanner frontmatter parsing with a standard-library fallback and corrected JSON output for non-ASCII paths.
- Expanded link auditing to anchors, URL encoding, images, directory README routes, symlink/root escapes, and missing targets.
- Added fixture-oriented scanner tests and negative invocation evals.
- Clarified the Agent-versus-script reasoning boundary, advisory-only audit behavior, and earned Authority Registry admission without adding a registry capability.

## Repository integration

- Retained repository-local AGENTS.md/Preset placement guidance and scanners.

- Kept `SKILL.md` focused on Locate/Classify/Route/Converge/Verify; AGENTS.md detail and mechanical-audit interpretation remain behind their task-scoped package references.
- Made template placeholders, source-anchor fixtures, and self-check compilation safe for the repository Suite audit.
