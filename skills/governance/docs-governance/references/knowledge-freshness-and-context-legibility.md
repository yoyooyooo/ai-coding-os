# Knowledge Freshness and Context Legibility

A documentation network is healthy only when an Agent can discover the current
owner and understand the claim at proportionate context cost.

## Context Legibility

Evaluate:

```text
path and title reveal purpose
scope and audience are local and explicit
Current / accepted-target / future are distinguishable
the semantic owner and Evidence route are discoverable
routers link instead of copying truth
only the relevant section must be loaded
unrelated history and repeated background are not forced into every task
```

More text is not automatically more legible. Prefer thin indexes, strong local
headings, direct references, and progressive disclosure.

## Knowledge Freshness

A critical claim should expose its basis and, when useful, `invalidates_when`:

```text
source path or schema changes
dependency/runtime version changes
accepted decision supersedes it
migration or authority epoch completes
observed environment or release changes
time-limited assumption expires
```

A stale map must be:

```text
re-grounded
marked drifted
lowered from current to source/history
superseded with a Route to the new Current Home
```

It cannot silently keep Authority because its file still exists.

## Durable Assumptions

A durable assumption has:

```text
owner
scope
reason it is safe enough now
commitments it cannot cross
expiry or invalidation condition
next decision or probe
```

Incidental local assumptions do not require a registry. Persist only when
handoff, risk, duration, or repeated reuse earns it.
