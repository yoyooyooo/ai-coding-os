# Goal Proof Sources

本目录保留已被消费但仍有追溯价值的 Goal Proof proposal、handoff 和 source note。

## Owns

- 实验 Goal Pack、CLI、方法文档或 review artifact 的历史输入。
- 从 source 到后续 artifact 的追溯关系。

## Must Not Own

- 当前 Goal Pack、tracker 或 ticket 状态。
- 当前 Product、SSoT、Standard、ADR、Architecture 或 Roadmap Authority。
- 开放 backlog。

## Boundary

Source 是历史输入，不是当前状态。后续 artifact 已接受的内容由其当前 owner 解释；本目录原文只保留当时上下文。
