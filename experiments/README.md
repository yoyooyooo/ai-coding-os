# Co-located Experiments

Experiments in this directory are maintained in the repository but remain outside the AI Coding OS core Skill Suite, Router roster, core audit, and core release bundle.

An experiment must declare:

- maturity and unresolved value;
- independent invocation and ownership;
- source, evidence, and execution-state boundaries;
- owner-local verification;
- promotion, retention, or retirement criteria.

- [Goal Proof](goal-proof/README.md) — user-invoked Goal Pack state/evidence method with an experimental CLI.
